# Fluent Emoji Flat ingredient assets

These SVG files are selected from [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji), using the `Flat` variants from the upstream `assets/` directory.

- Source: `microsoft/fluentui-emoji`
- License: MIT
- Local license copy: `LICENSE.txt`
- Integration: rendered as local `<img>` assets; no runtime request is made to GitHub or a CDN

The filenames were shortened when copied into this project. The SVG artwork itself is unchanged.
